# Black Eagle VPN — официальные выпуски

Репозиторий установочных файлов и подписанных каналов обновлений Black Eagle VPN.

## Android

[Скачать APK из Releases](https://github.com/kazievnadir-max/blackeagle-release/releases).
Android 11 и новее, ARM64. Для доступа к сервису используйте [Telegram-бота](https://t.me/BlackEagleVPNbot).

Начиная с 0.5.3 приложение проверяет обновления автоматически и вручную в настройках. Скачивание начинается по запросу пользователя, установку подтверждает Android. Для обновления поверх установленной версии нужна та же подпись APK. Более ранние версии требуют ручной загрузки первого APK с механизмом обновлений.

`channels/android-arm64.json` содержит подписанное описание актуального выпуска. Клиент проверяет подпись описания, размер и SHA-256 файла, идентификатор пакета, версию и сертификат APK. Контрольные суммы также приложены к каждому выпуску.

## Другие платформы

Подключение Linux, Windows и macOS будет выполняться поэтапно. Android использует отдельные теги `android-vX.Y.Z` и собственный канал обновлений.

Приватные ключи, пароли и GitHub-токены в этом репозитории не хранятся.
